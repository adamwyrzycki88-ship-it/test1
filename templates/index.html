About This PoC

This is a proof-of-concept implementation demonstrating the vehicle rendering pipeline. The production version would use .NET 8 / C# as requested.

Technology Used (PoC): Python Flask + CairoSVG + Pillow

Enhancements Applied:

  • Ground shadow for dimensional feel
  • Edge enhancement for polish
  • Proportional "fit in box" scaling
  • Watermark with opacity control

Performance Note: This PoC runs on a limited environment. .NET 8 version would be more performant with proper Azure hosting.

REST API Documentation

Endpoint

POST /render

Content-Type

multipart/form-data

Request Fields

  • vehicleSvg - The vehicle SVG file (required)
  • watermarkSvg - The watermark SVG file (optional)
  • maxWidth - Maximum width in pixels (default: 800)
  • maxHeight - Maximum height in pixels (default: 600)

Response

Returns image/png with the rendered image.

curl Example

curl -X POST -F "vehicleSvg=@car.svg" \
     -F "watermarkSvg=@watermark.svg" \
     -F "maxWidth=800" \
     -F "maxHeight=600" \
     http://localhost:5000/render -o output.png
